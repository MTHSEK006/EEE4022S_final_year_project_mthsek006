# Excel data: SDM Parameters from Nameplate

`SDMparametersfromdatasheet.m` needs no measured data. Its inputs are the nameplate (STC) values set at the top of the function: Voc = 21.6 V, Isc = 4.76 A, Vmp = 18.0 V, Imp = 4.44 A, Pmp = 80 W.

This folder can hold any exported results (for example, the identified parameter set).
